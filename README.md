# ML Benchmark Suite

Reproducible Iris classification comparison with stratified cross-validation and test metrics.

## Run

```bash
python main.py
```


Dependencies: `pip install -r requirements.txt`

## Notes

Demonstration code uses local, synthetic, or publicly available sample data. No proprietary banking/client data.
